# Personal Profile Card

A responsive personal profile card built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive dark-themed profile card
- Dark/light theme toggle (saved with `localStorage`)
- Show/hide biography
- Show/hide skills
- Copy email button with feedback
- Hover and focus states for interactive elements

## Getting started

1. Download or clone this repository.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Customize your profile details, image, social links, and email.

## Personalize it

- Replace `assets/profile.jpg` with your portrait.
- Update the name and biography in `index.html`.
- Replace `YOUR_USERNAME` in the GitHub and LinkedIn URLs.
- Replace `your-email@example.com` in both `index.html` and `script.js`.

Clipboard access works best on `localhost` (for example, with VS Code Live Server) or a secure HTTPS site.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage` and Clipboard API
